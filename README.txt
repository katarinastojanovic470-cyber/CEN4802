CEN4802 - Assignment 5: Implementing Application Containerization

Author: Katarina Stojanovic


Description

For this assignment, the Task Tracker application was containerized using Docker. The existing Maven build process was used to compile, test, and package the application before creating and running a Docker container. A source-code change was also made to include a complete button and an archived task list. The updated application was rebuilt and verified inside a new container.
