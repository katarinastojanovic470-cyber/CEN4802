CEN4802 - Assignment 3: Implementing Unit Testing in the Software Development Workflow

Author: Katarina Stojanovic


Description

For this assignment, the Task Tracker application has been configured with JUnit 5 to create and run automated tests. These tests will be used to verify various behaviors of the application are completed successfully with no errors, such as adding tasks in the proper format and rejecting invalid task description. The unit tests will be integrated with the Maven build process so that they can be automatically executed when the application is built.
